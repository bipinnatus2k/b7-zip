## 待办功能方向

> 2026-09-20 用户指定，按主题分组；实现顺序未定。完成后请移入「已完成阶段」或标注完成日期。

### A. 归档编辑模型

- **新建压缩文件（两种模式）**
  - 选择文件夹模式：对标 WinRAR，选定文件夹即创建压缩包。
  - 工作区模式：创建空白工作区，允许用户添加文件/文件夹，调整内部目录层级，排除条目，设置是否保留链接；整个编辑可保存为 JSON 格式的工作区编辑记录文件，支持二次编辑。
- **修改模式重构（change list）**
  - 现行 Git 式 stash/unstash（条目级暂存）过于繁琐，弃用；改为更贴合数据模型（vfs `Overlay`/`Changeset`）的 change list 形式。
  - 设计时考虑与「新建压缩文件 · 工作区模式」整合为同一套编辑模型。
  - 本条推翻 2026-09-16「Git 式修改区采用条目级暂存」的旧决策。

### B. 窗口布局重排

- **标题栏**：隐藏系统标题栏，只保留内置标题栏；内置标题栏右侧添加菜单按钮，点击显示应用菜单。
- **工具栏**：移到标题栏下方，并根据当前文档（激活 tab 的类型）切换内容。
- **状态栏合并**：explorer 内部的状态栏合并进窗口底部状态栏，内容随焦点所在 workspace 自动切换。
- **底栏控显按钮**：底栏的面板显隐切换按钮统一合并到状态栏右侧，其余原位置控件删除。

### C. 浏览与展示

- **当前目录导航**：压缩包当前目录的展示由字符串改为 gpui-kit 组件（面包屑式），实现导航位置功能（点任一级跳转）。
- **侧边栏 Tab**：Tab 不可由用户编辑，使用内置皮肤固定；左侧边栏的 Outline（目录树）Tab 改为注释展示，仅当归档有注释时才显示该 Tab。
- **Explorer 列扩展**：可展示列扩展到引擎能读到的全部属性（FFI/bit7z 层可见者皆可上表）。
- **预览栏**：Output 底栏改为文件预览栏——图片 ≤ 5 MB、纯文本文档 ≤ 500 KB 可预览；只读内存、不落盘；LRU 只保留 10 条；预览内容在后台任务中加载，避免卡住 UI；加载期间以 loading 态告知用户。

### D. 作业与系统集成

- **进度最小化联动**：进度窗口最小化（Background）时，托盘按钮与系统通知同时显示；系统通知使用 gpui 已有接口。
- **解压配置窗口**：解压前先弹出配置对话框（对标 WinRAR），暴露 FFI 接口中全部可指定项（输出路径、模式、密码、覆盖策略等）供用户配置。
- **Test 进度**：测试归档完整性作为 heavy job 必须显示进度。2026-09-18 已将 FFI 进度事件接入 TaskRunner，动工前先核实是未接 ProgressPanel 还是回归。

## 实施提示

- 耦合关系：「新建压缩文件」↔「change list 重构」需统一编辑模型；「标题栏」↔「工具栏」、「状态栏合并」↔「控显按钮」宜一批实施；预览栏依赖后台任务模式 + LRU；侧边栏注释可复用现有 `archive_comment` FFI 链路。
